# CyberShield

## Smart Phishing Detection System

CyberShield is a web-based security tool that analyzes URLs for common phishing indicators and provides a risk score.

## Features

- URL Scanner
- Risk Score
- Threat Detection
- Scan History
- Cyber Safety Tips

## How It Works

1. Enter a website URL.
2. Click "Scan URL".
3. CyberShield checks common phishing indicators.
4. A risk level and score are displayed.
